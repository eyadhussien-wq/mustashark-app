# MUSTASHAREK — Canonical Roadmap

This directory is the official roadmap reference for future Mustasharek engineering work.

- [`MASTER-ROADMAP.md`](./MASTER-ROADMAP.md) — master delivery and lifecycle map.
- [`MASTER-AUDIT-MAP.md`](./MASTER-AUDIT-MAP.md) — audit chain, Financial Isolation Gate, Financial Audit Integrity, and mapping rules.
- [`ROADMAP-REGISTRY.md`](./ROADMAP-REGISTRY.md) — roadmap ↔ repository traceability and verification evidence.

## Mandatory rule

Before writing code for any new task or PR:

1. assign the original Roadmap ID;
2. place it in the Master Audit Map;
3. identify Domain/Data/State/Security/D02 impact;
4. update the Roadmap Registry traceability record;
5. only then implement and validate.
